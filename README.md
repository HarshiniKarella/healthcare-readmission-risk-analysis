# Healthcare Readmission Risk Analysis

## Project Overview
Hospital readmissions within 30 days are a key indicator of healthcare quality and cost efficiency. This project analyzes diabetic patient hospital encounters to understand patterns associated with readmissions and builds a predictive model to identify high-risk patients.

## Objectives
- Analyze factors contributing to 30-day hospital readmissions
- Perform exploratory data analysis on patient and encounter data
- Build a predictive model to identify high-risk patients
- Create a Tableau dashboard for healthcare insights

## Business Context
This project is designed to support:
- Care coordinators in prioritizing follow-ups
- Clinicians in improving discharge planning
- Healthcare teams in reducing avoidable readmissions

## Tools & Technologies
- Python (Pandas, NumPy, Scikit-learn)
- SQL
- Tableau
- Jupyter Notebook
- Git & GitHub

## Dataset
UCI Diabetes 130-US hospitals dataset (1999–2008)
